# 0.1.1

Both `@whitekiwi/tokens` and `@whitekiwi/ui` release together.

- Replace the initial package READMEs with PIP covers, package selection guidance,
  installation steps, and practical examples
- Explain explicit and system themes, CSS import order, the React client boundary,
  public exports, and application accessibility responsibilities
- Include the existing MIT license in both inspected package archives

This is a documentation release. Runtime APIs and token values are unchanged
from 0.1.0. UI's token peer range is updated by pnpm to `^0.1.1` when packed.
